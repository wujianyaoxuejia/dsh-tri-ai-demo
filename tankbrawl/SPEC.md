# 坦克大乱斗 —— 规则与 Bot 协议

俯视迷宫坦克对战。炮弹撞墙反弹，一发即死，**可以打死自己**。

三辆坦克由三个独立程序控制（`bots/<name>.py`），裁判程序 `tankbrawl.arena` 组织比赛，产出 `replay.json` 供回放页播放。

## 场地

- 网格 32 × 20 格，每格边长 1 个世界单位。
- 第 0 行在最上方；`walls[y][x] == 1` 表示该格是墙，坦克与炮弹都不能穿过。
- 三张固定迷宫图：`pillars`（立柱阵）、`maze`（走廊）、`open`（开阔带掩体）。墙数据由 `tankbrawl.maps` 生成，对所有 bot 公开（静态地图不算作弊）。
- 出生点三处，每局轮换（每辆坦克都会轮到每个点）。

## 坦克

| 项 | 值 |
| --- | --- |
| 碰撞半径 | 0.45 格 |
| 移动速度 | 3.0 格/秒（方向 = 朝向） |
| 转向速度 | 3.0 弧度/秒 |
| 开火冷却 | 0.5 秒 |
| 同时在场炮弹 | 最多 3 发 |
| 视野 | 以朝向为中轴 ±75°，半径 12 格，**被墙遮挡** |

`angle = 0` 指向 +x，逆时针为正（与数学惯例一致，屏幕 y 轴向上）。

## 炮弹

| 项 | 值 |
| --- | --- |
| 速度 | 8.0 格/秒 |
| 半径 | 0.12 格 |
| 寿命 | 5.0 秒 |
| 最大反弹 | 4 次（第 5 次撞墙即消失） |

撞墙时按被撞的那一面做轴向反射：撞到竖直面就翻转 `vx`，撞到水平面就翻转 `vy`，角落同时翻转两者。

**自伤**：炮弹打中发射者本人，发射者死亡。

## 对局

- 三辆坦克混战，`dt = 1/60` 秒，决策频率 10 Hz（每 6 帧询问一次）。
- 结束条件：只剩 0 或 1 辆存活；或到 30 秒。
- 结束时只有一辆存活 → 它赢；0 辆存活（最后一次爆炸同归于尽）→ 平局；超时后多辆存活 → 并列平局。

## Bot 接口

```python
def decide(obs: dict) -> dict:
    return {"turn": -1.0 .. 1.0, "move": 0 | 1, "fire": True | False}
```

- `turn`：**连续量**，`1` 为逆时针满舵、`-1` 为顺时针满舵，`0.25` 就是四分之一舵。每帧转 `turn * 3.0 * dt` 弧度；超出 `[-1, 1]` 会被夹到边界。
- `move`：`1` 沿朝向前进，`0` 不动（只接受 0/1）。
- `fire`：`True` 且冷却完毕、在场炮弹 < 3 时发射。
- 返回值缺字段按 0 / False 处理；非法值（非数字、抛异常）→ 本帧视为全不操作，并给该 bot 记一次 `error`。整局 `error` 超过 20 次判该轮负。
- 同一场比赛里每个 bot 只能出一辆坦克，id 唯一；想测多辆请复制 bot 文件改名。

`obs` 结构（**只给看得到的东西**）：

```json
{
  "tick": 42,
  "time_left": 29.3,
  "me": {"x": 4.5, "y": 6.2, "angle": 1.57, "alive": true, "cooldown": 0.0, "shells_left": 3},
  "enemies": [{"id": "claude", "x": 9.1, "y": 6.0, "angle": 3.1}],
  "shells": [{"x": 7.2, "y": 6.1, "vx": 8.0, "vy": 0.0, "owner": "codex"}],
  "walls": [[0, 0, 1, "... 32 个数"]],
  "arena": {"w": 32, "h": 20},
  "spawns": [[3, 3], [28, 16], [16, 3]]
}
```

`enemies` 只包含**当前可见**（在视野锥内且视线未被墙挡住）的对手；`shells` 同理。看不到的目标不会出现在数组里，bot 不能靠“数组里没有”之外的任何信息推断。

## 禁止事项（沙箱强制）

- 禁止 `import`（`math` 除外），禁止 `__import__` / `open` / `exec` / `eval` / `getattr` 之外的内省。
- 禁止访问模拟器内部状态：`tankbrawl.sim` 等模块不在 bot 的可见全局里。
- 加载时静态扫描源码：出现 `import`（`from math import ...` 允许）、双下划线属性访问、`open(`、`eval(` → 直接判该 bot 不合格。

## 比赛与排名

- 每张地图 × 每个出生顺序（3! = 6 种）× 3 局；共 3 × 6 × 3 = 54 局。
- 计分：胜 = 1，平局 = 0.5 / 人数，负 = 0。
- 排名按总分降序；同分时按「存活总时长」降序。

## 命令行

```bash
python -m tankbrawl.arena --maps pillars,maze,open --rounds 3 --out runs/tb-001
python -m tankbrawl.arena --replay runs/tb-001/match-0001.json --viewer   # 合成单个回放
```

输出目录含：`standings.json`（排名）、`matches/*.json`（每局回放）、`summary.md`（人看的战报）。
